# 末轮出线状态修正协议

> 仅适用于小组赛**末轮（第3轮）**。前两轮不启用本协议，按纯实力 + 状态判断。
> 本协议修正的是「比分倾向」与 win/draw/loss 的相对高低，**不凭空逆转胜负关系**。

## 第一步：确认出线状态

开赛前先用 web 搜索确认两队的出线状态，各自归入下列之一：

- **已出线**（确定晋级，排名已锁定）
- **已出线但排名未定**（晋级了，但还在争小组第一/第二/净胜球/避强敌）
- **生死战**（必须拿分才可能出线）
- **已出局**（数学上无可能）

## 第二步：按状态组合做方向性修正

| 代号 | 状态组合 | 修正方向 |
|---|---|---|
| A | 双方都已出线 | 往**平局或小胜**调。降速、轮换、互不冒险是双方共同的理性选择，强队大胜概率显著下调 |
| B | 双方都已出线，且「打平即双双晋级、身后无人能追上」 | 往**平局**强修正。默契球最高风险信号，平局概率直接上调为最高项 |
| C | 一方已出线但需争头名/刷净胜球/避强敌，另一方已出局或为荣誉而战 | 往**大胜**调，强队有动机猛刷，启用 blowout 档 |
| D | 一方已出线（无排名压力，大概率轮换主力），另一方生死战必须赢 | 往**平局或弱方爆冷**调，弱方求胜欲 + 强方轮换拉近差距，强方信心下调 |
| E | 双方都生死战 | 往**强搏杀、可能大比分**调，双方全力压上、后防空虚，进球数倾向上调 |
| F | 强队已出线需大胜，弱方也已出局 | 往**大胜**调，无人阻挡，启用 blowout 档 |

## 第三步：幅度控制（防止过度修正）

- 方向性修正只调整 `scores` 的档位权重和 win/draw/loss 的相对高低，**不凭空逆转胜负关系**。实力差距巨大时，即便强队轮换，弱方「爆冷」也只是概率上调，不等于预测弱方赢。
- 「争净胜球」必须先搜索核实该队是否真有现实的反超空间（需要追几个净胜球、是否还依赖他场赛果）。若反超概率很低，则该队更可能「控制比赛保主力」，此时往中等比分收一档，不要默认大胜。这条用于避免高估刷净胜球的动机。
- 本协议判断的是「自身利益最大化」（保体能、争签位、刷数据、合谋晋级），**不是**「人情/不忍心让对手难看」。后者在职业足球中基本不存在，不作为修正依据。

## 第四步：写入 analysis

在 `analysis` 字段里必须**显式写出**两队的出线状态，以及本场据此做了何种方向修正（例：「墨西哥已锁头名大概率轮换 → 主胜信心下调、平局概率上调」）。`confidence` 要相应反映末轮的额外不确定性：出线状态导致动机扭曲的场次，信心不宜给「高」。
