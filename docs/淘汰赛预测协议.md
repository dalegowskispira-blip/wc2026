# 淘汰赛预测协议

> 适用于淘汰赛全部阶段（1/16决赛起，至决赛）。小组赛仍用《末轮出线状态修正协议》，两套各管各的阶段。
> 核心口径：`win`/`draw`/`loss` 与 `scores` 均指**法定90分钟**结果；晋级倾向（加时/点球）写在 `analysis` 里，不改胜负与比分口径。

## 一、相对小组赛「作废」的修正

淘汰赛是单场淘汰，小组赛末轮协议里基于「出线状态」与「动机扭曲」的修正**整套作废**：

- **出线状态分类作废**：淘汰赛每队都是生死战，没有「已出线/已出局」状态。
- **默契球 / 合谋平局作废**（原 Case A/B）：两队不可能同时晋级，无互利动机。
- **已出线方轮换主力作废**（原 Case D）：单场淘汰无人敢轮换，默认全主力。
- **控签位 / 避强敌作废**（原第四步）：只能打眼前对手，无路径可选。
- **刷净胜球 → blowout 作废**：净胜球在淘汰赛无意义，blowout 不再因刷球启用。

好处：淘汰赛预测回归**纯实力 + 状态 + 临场**，信号更干净。

## 二、淘汰赛新增 / 强化的判断点

1. **平局结构（90分钟）**：平局不再是终点，90分钟平 → 加时 → 点球。淘汰赛打法普遍保守（「不犯错」心态），**`draw`(90分钟)概率整体上调、进球数整体下调**，0-0 / 1-1 拖入加时更常见。
2. **低比分倾向**：淘汰赛场均进球低于小组赛，`scores` 往中小球收。`blowout` 档**仅在纯实力碾压**时启用。
3. **势均力敌 = 点球硬币**：实力接近的场，谁晋级接近五五开，`confidence` 明显下调，并在 `analysis` 写明「可能加时 / 点球决胜」。
4. **疲劳 / 停赛 / 加时余波**：上一轮打满120分钟、黄牌累计停赛（注：世界杯黄牌在1/4决赛后清零）、连续作战体能等，作为新变量核查。
5. **纯信号主导（保留强化）**：实力、近期状态、伤停停赛、主场 / 地理气候、历史交手——这些是淘汰赛的主导依据。

## 三、幅度控制

- 不凭空逆转胜负关系；实力差距巨大时，弱方「爆冷」只是概率上调，不等于预测弱方赢。
- `blowout` 只给实力碾压且对手确无抵抗力的场，且不与「保守低比分」倾向叠加误用。
- 仍**不**以「人情 / 不忍心」为依据（职业足球中基本不存在）。

## 四、写入要求

- `analysis` 字段必须**显式写出**：双方实力 / 状态对比、关键伤停停赛、为何给出该 90分钟倾向，以及**「若进加时 / 点球，谁更可能晋级」**的单独判断。
- `confidence`：势均力敌 / 点球级别的场不给「高」；只有实力明显占优且无重大不确定性时才给「高」。
- 铁律3 继续适用：海报 / analysis 不出现胜率%、推荐、稳等博彩词。
